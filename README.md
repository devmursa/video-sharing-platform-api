# video-sharing-platform-api
A backend API for a video-sharing platform built with Node.js, Express,
MongoDB, Mongoose, JWT, and Cloudinary.

## Features

- User registration and login
- JWT authentication
- Access and refresh tokens
- Password hashing and password change
- User avatar and cover image management
- Cloudinary image uploads
- Protected routes
- User profiles
- Subscriptions
- Video uploads
- Watch history
- Likes and comments
- Playlists
- Search and pagination

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Multer
- Cloudinary
